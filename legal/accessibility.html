Accessibility

Information about how we have designed Seeds of Hope to be accessible and easy to use.

Our approach

Seeds of Hope is a static educational campaign website created to communicate information about food security in Yemen. We aim to make the website clear, readable and easy to navigate.

Accessibility features

The website uses semantic HTML, descriptive headings, readable text and meaningful link labels. Images include alternative text where appropriate.

The website is also designed to work across different screen sizes, including desktop and mobile devices.

Feedback

If you experience an accessibility issue while using this website, please let the site creator know so it can be reviewed and improved.
